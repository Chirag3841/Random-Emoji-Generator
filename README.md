# Random-Emoji-Generator
Key Features:
✔ Built a CNN-based facial expression recognizer (TensorFlow/Keras) trained on labeled face images.
✔ Designed an emoji suggestion engine that maps emotions (happy, sad, angry, surprised) to dynamic emoji recommendations.
✔ Implemented data preprocessing (OpenCV) and augmentation to improve model robustness.
✔ Developed an interactive CLI menu for real-time emoji generation.

Technical Stack:
ML/CV: TensorFlow, Keras, OpenCV, scikit-learn

Python: NumPy, Matplotlib, pandas

Tools: Jupyter Notebook
 
What It Demonstrates:

Ability to create fun, interactive CLI tools

Working with Unicode/emoji representations

Simple but clean Python architecture
